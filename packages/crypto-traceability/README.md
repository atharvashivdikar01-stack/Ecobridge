# @ecobridge/crypto-traceability 🔗

Cryptographic hashing utilities, digital signature verification, and tamper-evident chain of custody for e-waste lot tracking.

## Key Responsibilities
- **Chain of Custody:** Calculates SHA-256 hash trees linking origin photos, GPS coordinates, and intake timestamps.
- **QR Pass Generation:** Signs and encodes batch verification payloads for offline gate entry.
- **EPR Certificates:** Cryptographic verification preventing double-counting of recycled materials.
