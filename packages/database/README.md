# @ecobridge/database 🗄️

Database schema, migrations, seeders, and client library for PostgreSQL 16 with PostGIS.

## Key Responsibilities
- **Prisma Schema:** Models for Users, Lots, Items, Facilities, Pricing, and Ledger Transactions.
- **PostGIS Extensions:** Spatial indexing for geographical proximity queries.
- **Data Seeding:** Provides realistic initial datasets (verified recyclers, material catalogs, benchmark prices).
