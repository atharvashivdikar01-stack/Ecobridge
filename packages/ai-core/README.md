# @ecobridge/ai-core 🧠

Vision classification definitions, quantized edge model assets (TFLite), hazard condition rules, and algorithmic fair-price mathematical formulas.

## Key Responsibilities
- **Class Labels & Thresholds:** Detection classes for electronics, batteries, CRTs, and boards.
- **Hazard Rules:** Safety alerts for swollen battery cells, toxic CRT glass breakage, and burnt components.
- **Pricing Logic:** Yield equations and net-earnings route optimization algorithms.
