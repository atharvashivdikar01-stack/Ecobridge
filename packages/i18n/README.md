# @ecobridge/i18n 🌐

Multilingual translation strings and localized voice prompt dictionaries.

## Supported Languages
- English (`en`)
- Hindi (`hi`)
- Tamil (`ta`)
- Telugu (`te`)
- Bengali (`bn`)
- Marathi (`mr`)

## Key Responsibilities
- **Translation Catalogs:** Strings for all UI interactions, safety messages, and lot stages.
- **Audio Dictionary:** Phonetic and text-to-speech script dictionaries for offline voice guidance in `apps/collector-mobile`.
