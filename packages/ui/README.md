# @ecobridge/ui 🎨

Shared design system, React component library, and Tailwind CSS tokens shared across `apps/recycler-portal` and `apps/admin-dashboard`.

## Key Responsibilities
- **Design Tokens:** Theme palette (eco greens, warm ambers, dark slate backgrounds, hazard reds).
- **Core Components:** Buttons, modal dialogues, data tables, metrics cards, badges, and form elements.
