# @ecobridge/admin-dashboard 🛡️

The **Admin & Regulatory Console** is a Next.js application for platform operators, sustainability auditors, and environmental regulators (e.g. CPCB/SPCB).

## Key Capabilities
- **Verification Queue:** KYC review for collectors and environmental permit verification for recyclers.
- **Geospatial Heatmap:** Real-time visibility into collection intensity, transit routes, and regional e-waste volume flows.
- **Fair-Price Policy Management:** Setting floor prices, platform margin caps, and fair-pricing parameters.
- **Regulatory Ledger Export:** Automated compilation of statutory compliance manifests (Form 2 / Form 3 ledgers).
- **Fraud Detection:** Real-time anomaly alerts for weight discrepancies or abnormal payment velocity.
