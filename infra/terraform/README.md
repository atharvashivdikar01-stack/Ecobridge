# infra/terraform 🌍

Infrastructure as Code (IaC) modules for provisioning ECOBRIDGE cloud environments (AWS / GCP).

## Provisioned Resources
- Managed PostgreSQL (AWS RDS Aurora / GCP Cloud SQL) with PostGIS extension.
- Object Storage Buckets (AWS S3 / GCP GCS) for e-waste lot photos and training datasets.
- VPC networks, private subnets, and security groups.
- Managed Redis (AWS ElastiCache / GCP Memorystore).
